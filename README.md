# OfficeSetu (ऑफ़िस सेतु)

> **"बोलो, लिखो या फोटो खींचो — ऑफिस का हर काम चुटकियों में!"**

OfficeSetu is a secure, cross-platform office automation mobile application built with Flutter. It features multi-modal inputs (Voice, Text, Camera) and aims for 100% data accuracy in daily office and administrative workflows.

## 🚀 Key Modules & Features
1. **Base UI & Dashboard:** Clean, modular, and fast interface designed for office workers and managers.
2. **Room 01: Attendance Matching (Smart Reconciliation):** Automatically extracts exit times from rough attendance registers and maps them with original register codes with 100% accuracy.
3. **Multi-Modal Support:** Integrated voice command processing and AI-powered camera scanning for documents and registers.
4. **Security & Sync:** Designed with high-security standards (E2EE) and seamless local-to-cloud synchronization.

## 🛠️ Tech Stack
- **Framework:** Flutter (Dart)
- **Version Control:** GitHub
- **Logic & Development:** Google AI Studio / Gemini
